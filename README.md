# 🎬 WatchWave

WatchWave is a modern movie discovery website built using **Html** , **Css** and **Bootstrap**. 
It provides users with an intuitive interface to discover trending, popular, and top-rated movies.
The application fetches real-time movie data from the TMDB API and offers a fast, responsive, and visually
appealing experience.

## ✨ Features

- 🎥 Browse Trending, Popular, and Top Rated movies
- 🔍 Search movies by title
- 📄 View detailed movie information
- ⚡ Fast performance with Vite
- 📱 Fully responsive design
- 🎨 Clean and modern user interface
